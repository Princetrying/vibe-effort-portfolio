# Personal Website Portfolio

## Description
A simple yet responsive personal portfolio website built using HTML, CSS, and Vanilla JavaScript. This project was originally created in 2025 during my exploration of front-end web development and website design.

The website was partially vibe-coded as part of experimenting with creative layouts, styling approaches, and learning through hands-on building. Despite being one of my earlier projects and staying archived in my files for quite some time, it still reflects the effort and curiosity I had while learning how HTML structures websites and how CSS enhances user interface design.

This project served as a personal practice space for understanding responsive layouts, basic web interactions, and clean front-end presentation.

## Features
- About Me section
- Responsive website layout
- Project showcase section
- External link addresses / social links
- Simple and clean interface

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
